Guayoyo es el primer proyecto que realizo sola en su totalidad, de principio a fin. Como todo buen desafío, está siendo un gran maestro.

Este espacio servirá como bitácora de los aprendizajes, observaciones o incidencias que se den en cada día durante el desarrollo de esta aplicación.

===========**Día 1**===========

**Lista de descripciones < dl >** - Tan pronto empecé me encontré con la primera duda ¿Qué etiqueta uso para el texto de la información de la receta? ¿Uso un h2,< p >? Así aprendí sobre los contenedores de datos clave-valor.

**id para JavaScript y class para CSS** - Así nos evitamos probleas de especificidad y facilitamos la repetición de estilos.

**aria-label y aria-hidden** - Importantes para las tecnologías de asistencia. Damos nombre al elemento y evitamos que el lector duplique lo que ya dice aria-label. También aprendí que Aria significa "Accesible Rich Internet Applications".

**disabled** - Para desactivar un botón antes de que tenga sentido usarlo. Luego se activa con JavaScript. Lo usé para desactivar el botón de pausa (en la página de preparación) antes de que empiece el temporizador.
